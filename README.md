Ukraine sinks a Russian corvette off Benghazi, Nvidia brings back Jensen
Huang, Trump warns Iran, Armenia's draft constitution opens a path to peace
with Baku, Alcaraz wins his first ATP Finals title, and COP31 ends with no
deal. A broadsheet front page, drawn in code with PIL.

## Entry

`main.py` (Python 3.13, standard library only, no network) copies the
committed `entry.png` (1024×1024, 119,555 bytes) to `/output/entry.png` and
verifies the copy is byte-identical. Run it twice and both runs write the
same bytes.

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
